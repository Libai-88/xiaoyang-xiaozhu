## 我们的故事

小羊和小猪的故事，开始于 2025.12.2。

那时候的我们，因为在“最右”上的一次偶遇认识，互相发现了有趣的灵魂，后来一点点熟悉，也一点点走进了彼此的生活。
刚认识你的时候，我就觉得你很可爱，也很喜欢你说话的风格，有一种很青春的感觉。和你聊天总是很舒服，也让我忍不住想慢慢地再靠近你一点。后来我们也从带有戒备，到慢慢放开内心，褪去了最初的陌生感。很多瞬间现在想起来，还是会觉得很温柔。

## 关于这个小站

这里是属于我们的小小空间。

我想把那些平凡却珍贵的日子都认真记下来：
一起吃过的饭、一起走过的路、一起拍下的照片、那些突然很想你时写下的话，还有每一个值得被记住的普通日常。

如果以后某一天回头来看，希望这里留下来的，不只是文字和照片，
也是我们一起走过的时间。

## 我眼里的你

你是一个温柔、可爱、有点像粘人精，也像个小屁孩一样的人。

你会撒娇，
也会在乖乖等我的时候，让我觉得特别心动。

有时候我会觉得，喜欢一个人并不是轰轰烈烈的事，
而是在很多很小很小的瞬间里，越来越确认：
“啊，就是你了。”

## 我们想一起完成的事

我们想一起去 everywhere，和你一起的话，哪里都想去。
我们想一起吃遍所有好吃的东西。
我想给你过几十次生日。
我们也想把以后更多普通的日子，慢慢过成值得纪念的日子。

## 写在最后

世界很大，但这里很小，
小到只放得下我和你。

希望未来的很多天里，
小羊还在写，
小猪也一直都在这。

## 这个站是怎么搭起来的

- **前端**：Next.js 16（App Router）+ React 19 + TypeScript + Tailwind CSS 4，部署在 Vercel。
- **后端**：FastAPI + PostgreSQL，部署在 Render，带基础缓存与安全响应头。
- **管理后台**：Vue 3 写的小后台，藏在 `/admin`。
- **域名**：用的免费域名，所以偶尔会抽风——正在想办法给网站加国内加速，让访问更稳一点。

一路踩了不少坑（Nginx 缓存、jsdom ESM 冲突、动态路由 500……），都记在部署笔记里了，有需要可以来交流。
